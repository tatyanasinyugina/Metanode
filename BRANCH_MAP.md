# METANODA Branch Map

This document distinguishes conceptual directions from Git branches. Git branches are version-control workspaces, not intellectual categories or proof of authorship.

```text
AUTHORIAL TRUNK
Tatyana Sinyugina's monograph, concepts, original methods and technologies
  |
  +-- Research and experiments
  |     +-- human development / Neuroclass
  |     +-- AI interaction and method adaptations
  |     +-- digital-twin transfer / network topology
  |
  +-- Digital ecosystem
  |     +-- source preservation and provenance
  |     +-- agent architecture and reproducible workflows
  |     +-- analytics and publication operations
  |
  +-- Applications and communication
        +-- education and development
        +-- research collaboration
        +-- strategic and public dialogue
```

This is a navigation model. It does not claim that every direction is fully implemented or independently validated.

## Attribution and status
1. The monograph and original technologies remain the authorial trunk.
2. Analyses, translations, AI adaptations, software, editorial work, and coordination must be attributed by actual contribution.
3. A branch name does not prove authorship, deployment, publication, or validation.
4. Distinguish designed, connected, validated, scheduled, published, and measured.
