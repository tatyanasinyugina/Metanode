# Реестр влияния и результатов

Задача раздела — документировать наблюдаемые последствия и вклад материалов Татьяны Синюгиной, не преувеличивая причинность.

Возможные уровни:
1. Охват и доступность — просмотры, загрузки, распространение.
2. Внимание и обсуждение — упоминания, запросы, экспертные обсуждения.
3. Использование — подтверждённое применение материала.
4. Изменение практики — изменение процесса, программы, инструмента или решения.
5. Результат — измеримое изменение у пользователей, организаций или в системе.
6. Долгосрочное влияние — устойчивые изменения, подтверждённые продольными или независимыми данными.

Для каждого утверждения фиксировать:
- точное утверждение о влиянии;
- какой источник Татьяны предположительно связан с результатом;
- механизм связи и хронологию;
- метрику, базовый уровень и период наблюдения;
- первичные данные и независимые подтверждения;
- альтернативные причины и ограничения;
- кто оценивал результат и возможный конфликт интересов;
- уровень уверенности и статус проверки.

Не использовать слова «доказало», «изменило отрасль», «внедрено», «привело к» без доказательной базы. Корреляция, последовательность событий и отзыв сами по себе не доказывают причинность.
