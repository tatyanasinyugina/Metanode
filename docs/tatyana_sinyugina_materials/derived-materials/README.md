# Производные материалы и результаты работы

Здесь регистрируются материалы, созданные на основе исходников: аналитические записки, переводы, протоколы, презентации, обучающие материалы, цифровые представления, программные компоненты, модели, промпты, наборы данных и публикационные тексты.

Каждый результат должен иметь:
- собственный ID и название;
- ссылки на все использованные источники и их версии;
- автора/исполнителя производной работы;
- описание преобразования и границ вклада;
- точные места заимствования, цитаты и ссылки;
- различение дословной цитаты, перевода, пересказа, анализа и гипотезы;
- версию, дату, статус проверки и путь к файлу;
- ограничения правового и этического использования.

Производный документ не становится авторским материалом Татьяны автоматически. Формулировки автора сохраняются в кавычках или с явной атрибуцией. ИИ-генерация маркируется как производная аналитическая/редакционная работа, если это существенно для понимания происхождения.
