# Ссылки, цитаты, упоминания и цитирование

Регистрировать любые формы обращения к материалам Татьяны Синюгиной:
- библиографическое цитирование;
- дословные цитаты;
- ссылки и гиперссылки;
- упоминания автора или названия системы;
- пересказы и содержательные отсылки;
- использование рисунков, таблиц, видео, аудио и иных объектов;
- включение в списки литературы, обзоры, презентации, курсы, отчёты, заявки, программные и коммерческие материалы.

Для каждой записи:
- ID и тип обращения;
- точный источник Татьяны и использованная версия;
- автор/издатель/организация, дата и название внешней работы;
- стабильный URL, DOI, ISBN, архивный URL или иной идентификатор;
- страница, раздел, таймкод или точное место цитаты;
- дословная цитата в допустимом объёме либо краткое описание упоминания;
- контекст и смысл использования;
- библиографическая запись;
- дата обнаружения и способ проверки;
- снимок/архив/файл доказательства;
- статус: обнаружено / источник открыт / содержание проверено / независимая проверка.

Различать:
- **ссылка** — URL ведёт на материал, но не обязательно содержит цитирование;
- **упоминание** — имя или название встречается в тексте;
- **цитата** — воспроизведён конкретный фрагмент;
- **библиографическое цитирование** — источник включён в библиографию;
- **использование** — содержимое реально применено;
- **влияние** — зафиксировано последствие, для которого отдельно проверена связь с источником.

Не объявлять найденную ссылку цитированием без проверки контекста. Не считать самоцитирование независимым внешним признанием. Соблюдать авторские права, условия лицензий и разумные пределы цитирования.
