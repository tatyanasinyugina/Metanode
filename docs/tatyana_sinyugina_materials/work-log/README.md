# Журнал работы с материалами

Фиксировать каждую содержательную операцию с источником отдельной записью: чтение, анализ, конспектирование, перевод, OCR, разметка, классификация, сопоставление, подготовка датасета, тестирование, цифровизация, передача на экспертную проверку.

Для каждой записи:
- ID события и дата;
- ID исходного материала и точная версия;
- исполнитель и роль;
- цель и основание работы;
- что фактически было сделано;
- применённые инструменты и метод;
- входные и выходные файлы;
- точные фрагменты/страницы/таймкоды, если применимо;
- отделение авторского текста от комментариев и интерпретаций;
- результат, ограничения, ошибки и открытые вопросы;
- проверка и ссылки на доказательства.

Не описывать намерение как выполненную работу. Не писать «изучено полностью», если проверена только часть. Для частичного просмотра указывать диапазон и полноту.
