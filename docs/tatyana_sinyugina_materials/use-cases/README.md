# Реестр случаев использования

Регистрировать каждый конкретный случай применения или использования материалов отдельно: исследование, образование, обучение, разработка, программный продукт, методическая работа, презентация, экспертное обсуждение, пилот, внедрение, коммерческое или общественное применение.

Обязательные поля:
- ID кейса;
- дата/период и организация/контекст;
- какой именно материал и версия использованы;
- кто использовал и в какой роли (если допустимо раскрывать);
- цель, способ и масштаб использования;
- прямое подтверждение: договор, письмо, протокол, публикация, запись, отчёт, репозиторий или свидетельство;
- что именно было использовано: идея, метод, текст, фрагмент, данные, изображение, программный артефакт;
- статус: заявлено / обсуждалось / запланировано / пилотируется / фактически применено / завершено;
- ограничения и разрешения;
- результат и ссылка на отдельную запись о влиянии, если оно оценивалось.

Не считать знакомство с материалом, получение письма, встречу, упоминание или интерес равными фактическому внедрению.
