# Реестр исходных материалов

Здесь ведётся каталог оригинальных материалов Татьяны Синюгиной и подтверждённых авторских версий.

Для каждого объекта использовать уникальный ID, например TS-SRC-0001. Не переименовывать и не перемещать оригинал без отдельного решения. Если оригинал находится в другом месте репозитория, указывать точный путь и SHA, не создавать дубликат без необходимости.

Обязательные поля:
- ID и точное название;
- автор / соавторы, если явно указаны в источнике;
- дата создания, публикации и версия — раздельно;
- тип и язык;
- исходный формат и местонахождение;
- Git path, commit/blob SHA, DOI, URL или архивный идентификатор;
- объём и полнота доступной копии;
- права и ограничения использования, если известны;
- статус проверки и дата последней сверки;
- связанные паспорта, записи о работе, производные документы, цитирования и кейсы использования.

Не выводить авторство только из имени файла, расположения или предположения.
