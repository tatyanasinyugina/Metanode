# Реестр доказательств

Здесь хранить или индексировать подтверждения для карточек источников, операций, кейсов использования, цитирований и влияния.

Примеры: письма с разрешением, официальные протоколы, DOI и страницы публикаций, архивные копии веб-страниц, договоры, отчёты, датированные скриншоты, логи выполнения, репозитории, независимые экспертные заключения.

Для каждого доказательства:
- Evidence ID;
- тип и краткое описание;
- дата получения и дата события, которое оно подтверждает;
- источник происхождения;
- путь/URL и контрольная сумма, если доступна;
- какие именно утверждения подтверждает;
- ограничения достоверности;
- конфиденциальность и разрешение на хранение/публикацию.

Не помещать в публичную ветку закрытую переписку, персональные данные или документы с ограниченным доступом. Для таких объектов хранить только минимизированную ссылочную запись в соответствии с разрешениями.
