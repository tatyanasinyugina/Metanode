# METANODA Library Index

This index is a navigation aid for existing materials. It does **not** define a new conceptual structure for Metanoda, replace the author's organization, or imply that the headings below are an authorial taxonomy. The system remains the larger whole; individual files, research questions, applications, and communication pieces are connected materials within it.

## Adding a new material

Preserve the original title and location where possible. Record author, date/version, type, language, source relationship, contributor roles, rights/consent status, and verification status. Link new work to the sources it actually uses without presenting it as a replacement for the established system.
