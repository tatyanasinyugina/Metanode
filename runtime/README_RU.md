# METANODA A0 — начальный исполнительный контур

Создан первый реальный GitHub Actions runner в ветке
`agents/social-media-execution`.

## Что он уже делает
- запускается при изменении runtime/operations в рабочей ветке;
- запускается вручную через GitHub Actions;
- проверяет наличие монографии Татьяны Синюгиной и двух рабочих handoff-документов;
- формирует однозначный статус проверки.

## Ограничения текущей версии
Это **не автономная AI-команда**. Сейчас исполнительная среда работает в безопасном
режиме READ_ONLY. В ней не настроены модельный API и внешние publishing adapters.
Публикация, изменение авторских источников и работа с личными данными запрещены.

## Следующий этап подключения
Отдельно подключаются модельный endpoint и минимально необходимые сервисные
credentials через GitHub Actions Secrets. Значения секретов нельзя хранить в
репозитории или передавать в чат. До подключения и теста эти адаптеры остаются
выключенными.

## METANODA AI Agent Team — новая версия

В ветке добавлены `runtime/metanoda_agent_team.py` и `.github/workflows/metanoda-agent-team.yml`.

Четыре последовательных AI-этапа: проверка публичного источника → стратегия → RU/EN редактура → независимый QA. Модель получает только публичный URL главного сайта и результаты предыдущих этапов. Ей не предоставляются инструменты чтения/записи репозитория, shell или публикации. Результаты сохраняются в `operations/agent_runs/`.

Публикация не выполняется: статус всегда `NOT_PUBLISHED`, пока отдельное разрешение и внешний publishing workflow не подтверждены. Доступ к Copilot CLI через защищённый Actions secret `COPILOT_GITHUB_TOKEN` обязателен. До добавления секрета реальный AI-run не подтверждён.
